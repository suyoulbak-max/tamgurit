개인정보처리방침

정적 페이지, 기기 저장소, 이메일 문의와 Google 광고 서비스의 정보 처리를 안내합니다.

최종 업데이트: 2026-10-13

1. 사이트에서 제공하는 기능

이 사이트는 회원가입, 댓글, 결제, 파일 업로드 기능 없이 교육 정보를 제공하는 정적 사이트입니다. 공개 페이지 코드에는 별도의 방문 분석 도구나 문의 내용을 서버로 보내는 폼이 없습니다. 콘텐츠 파일과 이미지는 GitHub Pages에서 제공되며, 외부 자료 링크를 누르면 해당 사이트로 이동합니다.

2. 접속 정보와 기기 저장소

페이지를 요청하면 호스팅 제공자는 IP 주소 등 연결에 필요한 정보를 처리할 수 있습니다. 제공자의 처리 기준은 GitHub 개인정보처리방침에서 확인할 수 있습니다. 사이트 운영자가 이용자의 브라우저 저장소를 서버로 전송하는 기능은 없습니다.

일반 페이지는 이전 CMS 데모에서 저장된 콘텐츠 설정이 있으면 기기의 localStorage에서 읽을 수 있습니다. 읽기 전용 관리자 데모의 접속 상태는 sessionStorage에 저장됩니다. 이는 회원 계정이나 실제 관리자 인증이 아닙니다. 브라우저의 사이트 데이터 삭제 기능으로 해당 기기의 저장값을 지울 수 있으며, 사이트 데이터 삭제는 광고 쿠키에도 영향을 줄 수 있습니다.

3. 이메일 문의

문의하기의 이메일 링크는 기기의 메일 앱을 엽니다. 링크를 누르는 것만으로 문의가 전송되지 않으며 사이트는 전송 성공을 표시하지 않습니다. 실제로 메일을 보내면 발신 주소, 본문, 첨부자료가 발신·수신 이메일 서비스에서 처리됩니다. 운영자는 수신한 내용을 문의 응답과 오류 확인에 이용할 수 있습니다. 학생 이름·학번, 학생부 원문, 건강 정보 등 불필요한 개인정보와 민감자료는 보내지 마세요.

사이트 코드만으로 수신 메일의 삭제 시점이나 이메일 제공자의 보관기간을 확인할 수는 없습니다. 보관과 삭제에 관한 구체적인 문의는 아래 이메일로 요청해 주세요. 확인되지 않은 고정 보유기간을 약속하지 않습니다.

4. 현재 포함된 Google 광고 코드

일부 공개 페이지에는 Google AdSense 광고 요청이 가능한 스크립트가 포함되어 있습니다. 계정 확인용 메타태그와 ads.txt는 이 스크립트와 별개입니다. 광고 스크립트가 로드되면 방문 페이지 주소, IP 주소, 브라우저 정보 등이 Google에 전달될 수 있습니다. 광고가 화면에 보이지 않아도 스크립트의 정보 처리가 없다고 단정할 수는 없습니다.

Google을 포함한 제3자는 광고 제공·측정, 부정 이용 방지와 설정·동의 조건에 따른 광고 개인화를 위해 쿠키를 저장하거나 읽고 웹 비콘, IP 주소 등의 기술을 사용할 수 있습니다. 이러한 정보는 광고 서비스 제공 과정에서 Google 및 관련 광고 파트너가 수집·이용·공유할 수 있습니다. 상세한 처리 방식은 Google 서비스를 사용하는 사이트에서의 정보 이용 안내와 Google 개인정보처리방침을 확인해 주세요.

5. 광고 활성화·동의와 이용자의 선택

현재 광고 코드가 제외된 글에는 해당 광고 로더를 넣지 않습니다. 향후 광고를 추가하거나 데이터 처리 방식을 바꾸면 고지도 함께 갱신합니다. 지역과 광고 방식에 따라 필요한 동의 절차가 달라지며, 이 문서나 일반적인 쿠키 안내가 필요한 동의를 대신하지는 않습니다.

Google의 광고 개인화 선택은 내 광고 센터에서 확인할 수 있습니다. 브라우저 설정으로 쿠키를 삭제하거나 제한할 수도 있습니다. 개인화를 끄는 것과 모든 정보 처리가 중단되는 것은 다릅니다. 제공되는 동의 메시지에서 선택한 내용을 변경하려면 해당 메시지의 관리 기능을 이용해 주세요.

6. 문의와 권리 요청

문의 메일의 조회·정정·삭제나 개인정보 처리에 관한 질문은 아래 연락처로 보내 주세요. 요청할 때는 필요한 최소한의 정보만 보내고, 다른 사람의 개인정보를 첨부하지 마세요. 호스팅·광고 제공자가 별도로 처리하는 정보는 각 제공자의 개인정보 안내와 권리 요청 방법도 함께 확인해 주세요.
