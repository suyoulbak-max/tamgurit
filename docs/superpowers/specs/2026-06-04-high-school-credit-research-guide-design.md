# 고교학점제 탐구가이드 설계 문서

작성일: 2026-06-04

## 1. 목표

`고교학점제 탐구가이드`는 고등학생과 학부모를 위한 한국어 정보형 정적 웹사이트다.

이 사이트는 단순한 탐구보고서 주제 예시 모음이 아니라, 다음 흐름을 한 번에 이해하도록 돕는다.

1. 고교학점제와 과목 선택 이해
2. 학년별 탐구보고서 방향 설정
3. 과목별·진로/계열별 탐구 주제 설계
4. 보고서 작성 흐름 정리
5. 세특 연결 포인트 점검
6. 서류기반면접 예상 질문과 꼬리질문 대비

사이트의 핵심 차별점은 `학년 × 과목 × 진로/계열 × 면접 대비` 구조다.

## 2. 타깃 독자

주 타깃은 학생과 학부모 혼합이다.

- 고등학생: 탐구보고서 주제 선정, 작성 흐름, 세특 연결, 면접 질문 대비가 필요하다.
- 예비 고1: 고교학점제와 과목 선택 구조를 쉽게 이해해야 한다.
- 학부모: 자녀의 과목 선택과 탐구 활동 방향을 이해하고, 대신 써주는 방식이 아니라 질문을 정리하도록 돕고 싶어 한다.

## 3. 핵심 원칙

- 학년별을 먼저 보여주고, 그 안에서 과목별·진로/계열별로 세분화한다.
- 입시 결과 보장, 합격 보장, 세특 만능 문구 같은 과장 표현을 사용하지 않는다.
- 탐구보고서는 제출물로 끝나는 것이 아니라 서류기반면접 질문으로 이어질 수 있음을 명확히 보여준다.
- 보고서 예시만 나열하지 않고, 주제 좁히기, 교과 개념 연결, 한계 분석, 윤리적 성찰, 꼬리질문 대비를 함께 다룬다.
- 모든 문장은 자연스러운 한국어로 작성한다.
- 허위 후기, 허위 통계, 허위 기관 정보, 허위 운영자 정보를 넣지 않는다.
- 광고 코드는 넣지 않는다.

## 4. 구현 방식

정적 HTML/CSS/JS 사이트로 구현한다.

이유:

- Replit에서 바로 실행하기 쉽다.
- 백엔드 없이도 정보 사이트와 CMS-lite 관리자 모드를 구현할 수 있다.
- 로딩이 빠르고 유지보수가 쉽다.
- 데이터 파일을 분리하면 글, 칼럼, 카테고리를 쉽게 수정할 수 있다.

## 10. 칼럼 3개 구성

초기 칼럼은 최소 3개로 구성한다.

1. 좋은 탐구보고서는 멋진 주제보다 좁은 질문에서 시작합니다
2. 탐구보고서의 한계 분석은 약점이 아니라 신뢰의 근거입니다
3. 세특과 면접을 생각한다면 결론에 윤리적 성찰이 필요합니다

칼럼은 정보글보다 운영자의 관점과 편집 원칙을 보여주는 역할을 한다.

## 11. 면접 대비 구조

면접 대비는 이 사이트의 핵심 차별점이다.

면접 대비 페이지와 글 하단에는 다음 요소를 포함한다.

- 탐구보고서가 서류기반면접 질문으로 이어지는 방식
- 기본 질문
  - 왜 이 주제를 선택했나요?
  - 이 탐구가 선택 과목과 어떻게 연결되나요?
  - 탐구 과정에서 가장 어려웠던 점은 무엇인가요?
  - 결과의 한계는 무엇인가요?
  - 진로와 어떤 관련이 있나요?
- 꼬리질문 유형
  - 방법론 검증
  - 교과 개념 검증
  - 한계 분석
  - 반대 관점
  - 윤리적 쟁점
  - 다른 분야로의 확장
- 답변 구조
  - 주제 선택 배경
  - 탐구 과정
  - 배운 점
  - 한계와 보완
  - 진로 연결

## 15. 디자인 방향

디자인은 교육 연구소형 정보 사이트를 목표로 한다.

- 입시 컨설팅 사이트처럼 과장된 분위기를 피한다.
- 학생도 쉽게 읽고, 학부모도 신뢰할 수 있는 정돈된 톤을 사용한다.
- 메인 컬러는 딥 블루 계열을 사용한다.
- 서브 컬러는 연한 블루/그레이를 사용한다.
- 강조 컬러는 차분한 민트 또는 네이비를 사용한다.
- 본문 가독성을 최우선으로 한다.
- 모바일에서 메뉴와 카드가 잘리지 않도록 한다.
- 카드 안에 또 다른 카드를 중첩하지 않는다.

## 17. 신뢰 페이지

신뢰 페이지는 실제 정보 사이트처럼 연결한다.

- About: 사이트 목적과 편집 방향
- Author: 운영자 소개, 편집 원칙, 칼럼 목록
- Contact: 이메일 기반 문의 안내
- Privacy: 개인정보처리방침
- Terms: 이용약관
- Disclaimer: 면책고지
- Sitemap: HTML 사이트맵

면책고지에는 다음 취지를 포함한다.

- 이 사이트는 일반 교육 정보 제공 목적이다.
- 특정 대학 합격이나 입시 결과를 보장하지 않는다.
- 학교별 평가 기준과 입시 제도는 달라질 수 있으므로 공식 자료와 학교 안내를 함께 확인해야 한다.

## 18. SEO와 접근성

- 모든 페이지에 고유 title과 meta description을 넣는다.
- Open Graph와 Twitter 메타 태그를 포함한다.
- canonical을 페이지 성격에 맞게 넣는다.
- H1-H2-H3 구조를 명확히 한다.
- 내부 링크를 자연스럽게 연결한다.
- 브레드크럼을 제공한다.
- Article, Breadcrumb, FAQ JSON-LD를 적절히 적용한다.
- `robots.txt`와 `sitemap.xml`을 포함한다.
- 이미지가 있을 경우 alt를 제공한다.
